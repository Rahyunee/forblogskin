# Sugarcoat

Blogger용 수익형 블로그 테마입니다. 예쁜 장식보다 가독성, 광고 슬롯, 모바일 속도와 유지보수를 우선합니다.

적용 파일은 `sugarcoat_blogger_theme.xml`입니다. 로컬 미리보기는 `preview.html`입니다. 적용 방법은 `APPLY_GUIDE.md`를 보면 됩니다.

## 파일

- `sugarcoat_blogger_theme.xml`: Blogger에 업로드하는 테마
- `preview.html`: 로컬 디자인 미리보기
- `DESIGN_ANALYSIS.md`: 원본 분석과 설계
- `APPLY_GUIDE.md`: 적용 방법
- `easypress_light_theme_v.1.2.5.xml`: 업로드된 원본 (참고용)

## 미리보기

`preview.html`을 브라우저로 열면 목록, 본문, 광고 자리, 사이드바를 한 화면에서 볼 수 있습니다.
